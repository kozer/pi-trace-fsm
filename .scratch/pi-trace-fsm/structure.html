Files to change

Proposed paths only. Each card states what is new and why.

index.tschange

New: pi extension entry point

Why: Owns lifecycle hooks, passive warnings, prompt context, and slash commands.

fsm.tschange

New: pure trace extraction and FSM model

Why: Keeps the paper-derived construction, prediction context, continuations, evaluation, and monitor deterministic and independently testable.

store.tschange

New: compact per-project persistence

Why: Stores activity-only traces without copying conversation content.

tests/fsm.test.tschange

New: behavior tests

Why: Verifies extraction, transition filtering, smoothed prediction, continuations, replay, evaluation, and risk metrics at the pure public seam.

scripts/smoke.tschange

New: extension smoke check

Why: Exercises the pure model, paper-style context, continuations, and evaluation with a runnable command without requiring an interactive pi process.

README.mdchange

New: usage and design documentation

Why: Documents loading, commands, storage, and the warning-only boundary.

Dependencies

  • index.ts → fsm.ts The extension feeds observed activities into the pure model and formatter.
  • index.ts → store.ts The extension loads and persists compact per-project traces.
  • store.ts → node:fs Persistence uses Node's standard filesystem APIs.
  • tests/fsm.test.ts → fsm.ts Tests call the deterministic model seam directly.

Public seams

  • Pi extension factory exported by index.ts
  • /fsm-status, /fsm-next, /fsm-evaluate, /fsm-mark, and /fsm-rebuild commands
  • buildModel(), predictNext(), continuationsFrom(), replayTrace(), inspectTrace(), and evaluateLabeledTraces() from fsm.ts

Test seams

  • extractHistoricalTraces() with session-shaped entries
  • buildModel(), predictNext(), continuationsFrom(), and evaluateLabeledTraces() with synthetic traces
  • TraceStore load/append/label/replace behavior
